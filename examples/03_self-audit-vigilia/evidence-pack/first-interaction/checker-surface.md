# Free compliance checker — the interaction surface

Captured 2026-09-06 from <https://aivigilia.com/about>.

**This surface changed between audit runs.** The first run of this audit
(2026-09-03) recorded no AI disclosure here and returned a MAJOR under Article
50(5). The operator shipped a fix on 2026-09-06. Both captures are kept: the
earlier one is preserved below so the finding that produced the change can still
be checked.

The checker takes a description of the visitor's AI system and returns a
generated risk classification with prose reasoning. It is an AI system the
visitor interacts with directly.

## Every string shown at and around the checker, in rendered order

Read from the live DOM at the form element, 2026-09-06.

```
Free · instant compliance check
Free preview — no card
No account required for preview
Not legal advice — technical gap analysis
Not sure where you stand? Describe your AI system.
Get an instant EU AI Act risk classification — tier, applicable articles, and
  governance gaps in seconds. No account required.
0/1000
This analysis is generated by Vigilia, an AI system.
Generate Compliance Snapshot →
```

While a request is in flight the button reads **"Analysing…"**.

## The disclosure, as observed

**A statement at this surface that the analysis is produced by an AI system is
present, and it precedes the control that starts the interaction.** Read from
the live DOM:

| Property | Observed |
|---|---|
| Text | "This analysis is generated by Vigilia, an AI system." |
| Element | `<p>`, live text, not an image and not a background |
| Position in DOM | before the submit button (`compareDocumentPosition` returns FOLLOWING for the button) |
| Position on screen | above the submit button, 24px clear of it, at 1280×900 |
| Computed colour | `rgb(0, 0, 0)` on the white ground |
| `aria-hidden` | not set |
| Typeface | Space Mono 13px, with a 2px solid black rule on its left edge |

It is repeated on the returned snapshot, on its own line beneath the result
header: "Generated by Vigilia, an AI system."

Both strings are localised and were confirmed live in all five languages:
`fr` "Cette analyse est générée par Vigilia, un système d'IA.",
`it` "Questa analisi è generata da Vigilia, un sistema di IA.",
`de` "Diese Analyse wird von Vigilia, einem KI-System, erstellt.",
`es` "Este análisis lo genera Vigilia, un sistema de IA."

The site footer disclosure — "Vigilia is an autonomous AI agent, operating with
human oversight" — still sits below the checker. It is no longer the only AI
disclosure on the page, and the verdict no longer rests on it.

## The superseded capture, 2026-09-03

Kept verbatim, because a remediation is only checkable against what it replaced.

> ## What is not there
>
> **No statement at this surface that the analysis is produced by an AI system.**
> The strings above describe the output ("instant", "classification", "snapshot")
> and disclaim legal advice, but none of them tells the visitor that the thing
> answering them is an AI system.
>
> The only AI disclosure reachable from this page is the site footer —
> "Vigilia is an autonomous AI agent, operating with human oversight" — which sits
> below the checker, after the point of interaction, and is a statement about the
> publisher rather than about this tool's output.

## Source of the strings

`vigilia/messages/{en,fr,it,de,es}/checker.json` (`form.aiDisclosure`,
`results.aiDisclosure`, `form.descriptionLabel`, `form.submit`,
`form.submitting`) and the rendered `/about` page.
