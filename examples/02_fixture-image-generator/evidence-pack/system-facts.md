# System facts — PixelForge

| Question | Answer |
|---|---|
| Legal entity | PixelForge B.V., Rotterdam |
| Product | PixelForge — a web app that generates images from a text prompt |
| Provider, deployer, or both? | **Provider.** PixelForge builds and operates the service under its own name. Customers who generate and then publish images are deployers in their own right; this audit does not cover them. |
| Output modalities generated | **Image only.** Photorealistic and illustrative stills. No audio, video or text generation. |
| Available to persons in the EU? | Yes. |
| Placed on the market | **2026-01-15** |
| Put into service | 2026-01-15 |
| Emotion recognition present? | No. |
| Biometric categorisation present? | No. |
| Does the service itself publish generated images? | No. Images are returned to the user who requested them. PixelForge publishes nothing. |
| Law-enforcement authorisation claimed? | No. |
| SME / SMC? | SME (19 employees). |
| Marking technique used for generated images | **None.** No C2PA manifest, no IPTC digital source type, no watermark, no steganographic mark. A visible "Made with PixelForge" caption is offered as an optional export setting, off by default. |
